---
title: "ChartScribe"
description: "cscribe maintains the Zettelkasten note format of the chartroom collection."
---
ChartScribe is a Go CLI (`cscribe`) for plain-text Zettelkasten collections: it validates
notes, creates, lists and links them, writes the configuration of the preferred tools and
generates issue-tracking sections.

Status: pre-alpha. The first spec is
[001-note-tooling](https://github.com/wstein/chartscribe/blob/main/specs/001-note-tooling/spec.md).
The source is at <https://github.com/wstein/chartscribe>.
